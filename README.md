# tesseract-research

The public site for Jonathan Carroll's ResearchJobs project: **https://jace0228.github.io/tesseract-research/**

Content is generated by the project's pipelines and pushed here by a daily job; nothing on this site is edited by hand
except the landing page. See the site for the rules (blind recovery gates, frozen predictions, AI disclosure).

- `lunar-sentry/` — Moon impact probabilities for known asteroids (table + JSON)
- `moon-watch/` — impact-flash forecasts, calendar and RSS feeds, scoreboard
